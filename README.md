# Elin-party-care-mod

ElinのMOD制作メモ。最初は仲間の世話を自動化する。

## 最初の試作

- **包帯の自動使用** — プレイヤーが包帯を1個以上持っていると、負傷した仲間が自動で包帯の効果を受ける。手持ちの包帯の数は減らない。試作ではHPが半分以下を発動条件とする。
- ゲーム内で、包帯が1個あれば回復し、個数が1個のままで、0個なら発動しないことを確認する。

## 次に作りたい機能

- **食事の自動化** — 空腹の仲間がプレイヤーの手持ちの食べ物を使って自動で食事する。手持ちの食べ物の数は減らない。どの食べ物を選ぶかは未定。

## 今後のMOD案

- **スロットの自動化** — Elin内のスロットで絵柄を自動でそろえる。対象の絵柄や操作方法は未定。
- **大規模MOD** — 小さなMODで作成から動作確認まで経験を積み、将来は規模の大きいMODにも挑戦する。
